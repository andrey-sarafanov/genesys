# Sources and maintenance

Use version-specific Registry or tagged official GitHub docs for Terraform fields/permissions, Developer Center/API Explorer for APIs and authoring, and Resource Center for channel behavior. Check installed CLI help before running commands.

- [CX as Code](https://developer.genesys.cloud/devapps/cx-as-code/)
- [Official provider](https://github.com/MyPureCloud/terraform-provider-genesyscloud)
- [Registry](https://registry.terraform.io/providers/MyPureCloud/genesyscloud/latest/docs)
- [Archy](https://developer.genesys.cloud/devapps/archy/)
- [API Explorer](https://developer.genesys.cloud/devapps/api-explorer)
- [Platform CLI](https://developer.genesys.cloud/devapps/cli/)

The user's [Explorer](https://cxascode.github.io/) is an unofficial dependency/version/export reference; verify its suggestions. The user's [community discussion](https://community.genesys.com/discussion/i-wrote-a-tutorial-on-using-cx-as-code) links [Lucas Woodward's tutorial](https://makingchatbots.com/p/cx-as-code-with-genesys-cloud) and its [MIT-licensed demo](https://github.com/MakingChatbots/genesys-cloud-cx-as-code-demo). Older tutorial version-specific syntax needs verification.

Seed assets adapt MIT-licensed [official provider examples](https://github.com/MyPureCloud/terraform-provider-genesyscloud/tree/v1.87.0/examples/resources/genesyscloud_flow), [official bot blueprint](https://github.com/GenesysCloudBlueprints/deploy-webmessaging-chatbot-with-lambda-blueprint), and the tutorial demo. Preserve accompanying notices in generated projects. Refresh from target-org exports when needed.

Research baseline: October 13, 2026; provider 1.87.0, not a permanent latest claim. [Codex AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md) documents repository guidance discovery.
