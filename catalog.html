Using the skill

When to use it and what to provide

These are the three Genesys-specific skills installed in the reviewed environment. Choose the skill by the task you need completed.

Genesys Reporting

Authentication, Analytics APIs, permissions, KPI interpretation, extraction and incremental reporting pipelines.

$genesys-reporting

CX as Code

Build IVR, voicebot and messaging journeys with Terraform, Architect YAML, channel wiring and release validation.

$genesys-cx-as-code

Performance Investigator

Investigate selected queues/flows using daily and intraday evidence, weighted analysis and an offline HTML report.

$genesys-performance-investigator

A practical sequence

Use Reporting to establish access and reliable acquisition. Use Performance Investigator when the task is a scoped diagnostic report. If the evidence leads to an authorized journey change, use CX as Code to implement and verify it. These skills can support one another; documentation or reporting alone does not authorize a production configuration change.

Reading

Use the guides online or offline

Each guide contains a contents menu, full-text section search, usage examples, reference detail and the skill instructions. Code blocks can be copied. The guides are self-contained and can be downloaded for offline viewing.

GitHub’s repository viewer shows HTML source. Download the files and open catalog.html locally, keeping the HTML files together so the guide links work.
